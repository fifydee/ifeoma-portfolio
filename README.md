# Ifeoma Degge — Personal Portfolio

A concise editorial portfolio for AI-powered storytelling, digital products and research-led experiments.

## Editing projects without code

The project collection is configured for [Pages CMS](https://app.pagescms.org/). Sign in with GitHub, install the Pages CMS GitHub App for this repository, and open this repository. The visual editor will let you add projects, upload cover images, paste YouTube/Vimeo links, describe the brief/process/outcome, and choose Draft or Published.

The site reads project entries from `content/projects.json`. Only entries marked `Published` appear publicly. Supported YouTube/Vimeo links are embedded in the project detail view.

## Publishing

Recommended hosting: Cloudflare Pages connected to this GitHub repository, using branch `main`, no build command, and `/` as the output directory. The site is plain HTML, CSS and JavaScript.

## Before launch

- Add the supplied wide Ifeoma Degge logo asset; the current navigation uses a temporary text wordmark.
- Confirm the public contact method and replace the social-link placeholder in the contact section.
- Add real project content and cover images through Pages CMS.

## Field Notes

A separate Field Notes page is available at `field-notes.html`. Manage posts in Pages CMS under **Field Notes**. Add a title and unique URL slug, choose one of the seven categories, write the article in the rich-text editor, optionally upload a cover image, and choose Draft or Published. Drafts stay hidden from the public page.

The first published note is **How I Built My Portfolio Website with ChatGPT and GitHub**.
